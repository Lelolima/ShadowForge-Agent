## Defeitos encontrados executando os fluxos (todos corrigidos)
- `0.0.0.0/0` na blacklist padrão bloqueava todo IPv4: qualquer campanha ficava presa em "bloqueada" por até 1000 ciclos.
- A fase de recon nunca executava (a fase avançava duas vezes).
- `ReconScanner` não tinha como autorizar alvo nenhum; o parser de XML do Nmap descartava todos os hosts.
- O bloco `ooda` do YAML era ignorado.
- O relatório não era salvo, e uma falha virava "sucesso". Com 0 vulnerabilidades, o texto dizia risco "MODERADO".
- A captura de tela rodava sempre e, com API key, era enviada à nuvem (agora é opt-in).
- `core.security.__all__` exportava um nome inexistente; um typo desativava o PDF; havia uma classe duplicada.
- Fases ilustrativas apareciam como resultados reais (agora rotuladas `[SIMULADO]`).

## Salvaguardas adicionadas
- Escopo obrigatório fora do dry-run (`--scope`/`--scope-file`).
- Confirmação fail-closed (`--yes`).
- Trilha de auditoria JSONL com hash encadeado.
- `--dry-run` e `--check-config`.
- Encerramento após bloqueios repetidos.

Nenhuma capacidade ofensiva foi adicionada.

## Decisões registradas
- Os exemplos antigos (só imprimiam texto fixo) foram removidos e substituídos por cenários reais.
- `core/action_strategies.py`, `core/subsystem_factory.py` e `core/protocols.py` foram removidos: não tinham nenhum import.
